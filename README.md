# Poultry-3D

Online 3D Design for Circular Poultry Development.

## Circular Poultry Interactive Model

This is the reviewed and corrected version of the Google AI Studio prototype.

## Open it

1. Open a terminal in this folder.
2. Run `pnpm install`.
3. Run `pnpm run dev`.
4. Open the local address shown in the terminal.

Click any named station in the right-hand list or click its object in the 3D scene. The information panel includes a station name, confirmed/proposed status, a web-sourced illustrative image, project explanation, walkthrough, circular flows and grant alignment.

## Evidence rule

The interface distinguishes signed-project facts from illustrative or proposed design ideas. Physical dimensions, capacities, equipment schedules and outcomes must not be presented as confirmed unless a project source supports them.
